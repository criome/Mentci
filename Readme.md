# Medi — **The Sema Interface**

Medi is the **human interface to Sema**: the environment in which symbolic
intent becomes directly intelligible and directly editable.

Medi renders Sema in forms a human psyche can perceive, navigate, and work with,
while preserving the precision and authority of the underlying symbols.
Interaction in Medi is interaction with Sema itself. Reading, modifying,
composing, and exploring are not separate modes; they are continuous ways of
engaging the same symbolic structures.

There is no qualitative distinction between using software and creating it. What
appear elsewhere as applications, configuration, or code are, in Medi, different
presentations of **the same act: shaping symbolic intent**. Differences lie only
in how intent is rendered, not in what is being changed.

Medi renders Sema **adaptively**. The same symbolic content may appear
differently depending on language, knowledge, skills, habits of thought, or
cognitive strengths and limits. This adaptation affects presentation and
guidance, not meaning. Symbols remain stable; intelligibility is what varies.

Medi is therefore a **shared environment for human engagement with symbolic
intent**, where understanding and modification converge, and where interaction
with computers no longer divides into use versus authorship, but unfolds as a
single, continuous practice.
